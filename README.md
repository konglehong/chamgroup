# ChamGroup / Chạm

Repository khởi tạo cho website ChamGroup / Chạm.

## Mục tiêu

Website giới thiệu hệ sinh thái Chạm trong các lĩnh vực:

- Phong thủy kiến trúc hiện đại
- Kiến trúc
- Nội thất
- Thi công hoàn thiện
- Diễn họa hình ảnh CGI / phối cảnh 3D
- Truyền thông thị giác cho thương hiệu và dự án

Định hướng tổng thể: chuyên nghiệp, thẩm mỹ, sáng, sang, giàu cảm xúc, không mê tín, không dị đoan, dễ hiểu với khách hàng cá nhân và doanh nghiệp.

## Brand core

**Phong thủy kiến trúc hiện đại là trọng tâm của Chạm.**

Cách tiếp cận cần dựa trên:

- Ánh sáng tự nhiên
- Thông gió
- Tỷ lệ không gian
- Dòng di chuyển
- Công năng sử dụng
- Vật liệu
- Màu sắc
- Cảm nhận tâm lý trong không gian sống

Không dùng ngôn ngữ mê tín, hù dọa, thần bí hóa hoặc khẳng định thiếu cơ sở.

## Brand colors

- Blue: `#127dc2`
- Gray: `#808184`

## Local preview

Với bản HTML/CSS tĩnh ban đầu, có thể mở trực tiếp `index.html` trên trình duyệt.

Nếu sau này chuyển sang Vite/React:

```bash
npm install
npm run dev
```
