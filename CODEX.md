# Codex Instructions for ChamGroup

## Project identity

This repository is for the ChamGroup / Chạm website.

The website must position Chạm around **modern architectural feng shui** as a scientific, spatial, human-centered design discipline — not superstition.

## Core rule

Do not write content that sounds mystical, fear-based, fortune-telling, or superstitious.

Preferred language:

- spatial experience
- light and ventilation
- orientation and microclimate
- circulation flow
- human comfort
- material balance
- functional zoning
- psychological comfort
- evidence-informed design

Avoid language:

- magic
- fate prediction
- guaranteed wealth/luck
- spiritual threat
- fear-based feng shui claims
- superstition or ritual claims

## Design direction

Visual direction should be close to premium architecture portfolio websites:

- quiet luxury
- clean typography
- generous whitespace
- editorial layout
- large architectural imagery
- subtle interaction
- bright, elegant background
- minimal but emotional

Reference inspiration: MIA Design Studio style, but do not copy exact layout, text, or assets.

## Brand colors

```css
--blue: #127dc2;
--gray: #808184;
```

Use these as brand anchors, but keep the overall palette soft, architectural, bright, and premium.

## Technical baseline

Current baseline is static HTML/CSS:

- `index.html`
- `css/style.css`

Keep CSS clean and centralized in `css/style.css`.

## Responsive requirements

Every page/section must work on:

- desktop
- tablet
- mobile

Hero/banner sections should be full width unless explicitly constrained.

## Commit discipline

Use small, clear commits. Example commit messages:

- `Add homepage hero section`
- `Refine ChamGroup brand typography`
- `Fix homepage banner full width`
- `Add modern feng shui service section`

## Before finalizing changes

Check:

- Vietnamese typography displays well
- accents are not broken
- hero/banner is full width
- mobile layout does not overflow
- content avoids superstition
- color palette remains bright and premium
